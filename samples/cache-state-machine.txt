CSC 436 Week 5 — shared-cache state machine, captured from edge.mjs + origin.mjs
Generated by capture-transcripts.mjs. Cache key mode: conservative.

/api/status carries: public, max-age=0, s-maxage=10,
                     stale-while-revalidate=30, stale-if-error=600
Its bytes only change when someone POSTs /admin/bump, so the ETag is stable
between changes -- which is what makes REVALIDATED reachable.
